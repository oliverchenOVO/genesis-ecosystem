# AI 協作與貢獻揭露

本專案使用 Codex 協助實作、除錯、測試執行、benchmark、實驗診斷與文件整理。最近 R4 工作中，使用者指定研究範圍、不可降低的驗收標準、determinism／save／replay 要求，以及不得將 LLM 放入核心 simulation loop 的約束；Codex 在這些約束內實作與執行測量。

AI 開發協助與模擬運行是兩個不同層次：程式開發過程使用 AI，運行中的核心世界狀態由 Rust 規則與固定 RNG 次序決定，沒有 LLM 決定世界真相。

測試、CI、保存的原始實驗資料與 commit 歷史是可檢查的產物；它們不自動證明每個結果的科學有效性，也不能代替作者對實作的理解。
