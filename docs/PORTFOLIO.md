# GENESIS：可重現的人工生命模擬研究原型

GENESIS 探索如何從單細胞個體、遺傳性狀、資源取得與繁殖規則產生演化現象。Rust 核心決定世界狀態，Tauri 與 React 顯示實際紀錄。這是人工生命模型，沒有宣稱能預測真實生物演化。

## 工程與研究重點

- 固定 seed 與確定性核心：相同初始條件、指令與 tick 次序應重現相同世界 hash。
- 保存、載入與完整 replay：以重建世界驗證結果，而非只比較畫面；包含載入後續跑的檢查。
- 模擬與呈現分離：介面更新頻率不改變模擬 tick 的意義；核心不依賴 LLM。
- 證據導向的實驗：保留原始測量、來源 patch、執行檔 hash 與驗收門檻，未達標的候選方案被拒絕。
- 診斷工具：分析時間窗內的實際飲食、資源空間結構、生命週期能量與配偶可得性；大型資料以可驗證的壓縮 sidecar 保存。

## 已量測結果與限制

| 項目 | 可引用的結果 | 必須一起說明的限制 |
| --- | --- | --- |
| R3 正式 headless 校準 | 100 seeds × 100000 ticks；100/100 save/load、完整 replay 與續跑驗證通過 | 四項生態驗收門檻仍為 0/100；不是 R4 正式校準 |
| R4 有界候選實驗 | 5 組情境 × 8 seeds × 50000 ticks；40/40 重現驗證通過 | 包含一組控制與四組候選，四個候選皆失去持續多細胞存活，未採用 |
| 本機回歸 | Rust normal 75、all features 84、前端 24、Node 26 通過 | 測試通過不等於生態或原生安裝驗收完成 |
| 效能分析 | 已保存成對 benchmark 與 profile；perception 約占標記階段時間 88.94% | 主機量測波動明顯，尚無穩定效能達標結論 |

上述數字來自 R4 收尾基準 commit `83b13e7`；公開準備文件的後續 commit 不代表新的生態實驗。完整定義、來源與限制見 [驗收報告](PHASE2_REPORT.md)。

候選失敗仍提供了可檢查的結果：僅增加資源場的空間尺度或提高捕食能量回收，沒有建立符合門檻的穩定複雜生態。診斷資料也沒有支持直接加強餵食 trade-off；下一步應以保留的時空與交配資料提出另一個有界假設。

## 建議審閱路徑

1. 閱讀 [架構](ARCHITECTURE.md)、[determinism](DETERMINISM.md) 與 [replay](REPLAY.md)，理解核心邊界。
2. 閱讀 [R4 報告](PHASE2_REPORT.md) 的候選矩陣，對照原始驗收門檻與拒絕理由。
3. 檢查 `crates/sim-core`、`crates/sim-benchmark` 與 `scripts/temporal-ecology-checks.mjs`，看實作與測量如何互相驗證。
4. 依 README 在本機建立固定 seed 世界，保存、載入並執行介面的 Verify replay。模擬分化可能需要長時間；短展示不保證出現物種分化。
