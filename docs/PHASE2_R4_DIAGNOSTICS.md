# R4 temporal diagnostics, stage A

Authority remains simulation5 / rules3 / RNG1 / envelope1 / analysis5. The additive `ecology.r4_temporal.version=1` identifies the new optional observer; the sealed R3 ecology4 fields and biological acceptance are unchanged. R3 cfef69e is protected by `phase2/r3-frozen-cfef69e`, the exact R3 report archive, archived R3 golden, and a preservation manifest. No rules4 candidate has been selected.

The observer is compiled only with `viability`. It has no authoritative state, RNG, persistence or frontend fields. It reuses the existing event hooks and an independently constructed bounded spatial grid at100-tick snapshots. Resource snapshots scan the grid once per1000 ticks outside perception. No full-population scan occurs inside an organism query. Each individual keeps only its current1000-tick counters; at the boundary these are reduced to world/lineage/realized-role summaries and discarded. There is no full individual event archive.

Disjoint diet intervals contain ticks1..100,101..200, etc. Endpoint samples include tick0. Disjoint budgets cover1..1000,1001..2000, etc. Founder and final censored counters occur in the first and last budgets respectively. Window closure uses explicit boundary populations and energy stocks, births, removals, credited resource/prey income and actual expenditure, rather than assuming every window starts empty. Parent offspring and successful-mating participations differ from births and pair counts. Requested hunting movement and actual total metabolism during hunting are separate observations: depleted energy does not permit attribution of all requested movement cost as actual spending.

The external temporal analyzer derives1000 and5000-tick windows. A qualified lineage needs at least8 living members at every100-tick endpoint within a full window. SoftSpecialist means>=70% credited soft energy; HardSpecialist>=70% hard; PreySpecialist>=50% prey; otherwise Mixed, and zero income is NoIncome. Post-warmup persistence starts after tick5000. Missing, unqualified and zero-income windows break streaks. These classifications are diagnostics, never replacement acceptance gates.

Every window retains population, traits, habitat, position/extent, food/prey channels, processing efficiency, stock, local opportunities, births/deaths, lifespan, offspring and actual energy budgets. Individual1000-tick realized diets yield separate within-world/within-lineage fitness groups, so a lineage-wide Mixed diet is not taken as proof that all its members are generalists. Comparisons are descriptive; conditioning on contemporaneous diet or completed deaths is not a causal survival estimate. No juvenile/adult state exists in authority, and completed lifespan must not be called adult lifespan. Censored lifetimes remain separate in the inherited ledger.

Local opportunity snapshots use authoritative eligibility, compatibility, can_attack and vision. The mate distance is16; attack distance8. Counts exclude self and apply exact circular distance after spatial lookup. All mouths share density strata of other residents within16:0,1..2,3..7,8+. Ready-only sample counters permit density-controlled comparisons between predators and Grazer/Crusher. These observations occur after tick resolution, so they do not incorporate paired exclusions and are not actual matching-attempt counts. Real attempts, kills, offspring and starvation come from event ledgers.100-tick displacement is a lower bound on path length.

Spatial analysis reads soft/hard stock and uncapped productivity numerators at1000-tick snapshots. Quantile masks use the descending ceil(N*fraction) cutoff for top25% and50%, include every tied positive cell, and exclude zero stock. Connected components use four neighbours, without wrapping. Perimeter includes map edges. Areas are world units squared, perimeter and distances world units. Nearest same-rich distance excludes self. Pearson autocorrelation pools horizontal/vertical cell pairs at lags16..128; approximate correlation length is the first lag<=exp(-1). If no crossing occurs it is right-censored at the maximum measured lag; constant fields return null, not a fabricated zero. Snapshot patch matching independently maximizes Jaccard for each prior component; splits/mergers are permitted and non-overlap is explicitly unmatched. Global mask overlap, centroid movement and area ratios accompany component summaries. Both stock and static productivity are measured because consumption-driven stock fragmentation alone cannot justify changing production.

CLI: `node scripts/summarize-temporal-ecology.mjs INPUT.json[.gz] OUTPUT.json`. It rejects incomplete worlds, missing snapshots/samples, failed replay/continuation, temporal energy/population mismatches and individual fitness inconsistencies. It accepts only full1000-tick calibration boundaries. Raw100-tick data are retained for inspection alongside summaries.

For large runs, `sim-benchmark --calibrate ... --output artifacts/run.jsonl --diagnostics-dir artifacts/run-worlds` writes one compressed temporal sidecar per completed seed. Both destinations must be fresh siblings; existing journals/directories/files are refused. The normal report retains every original ledger and a relative `r4_temporal_ref` containing seed, tick, schema, uncompressed byte count and SHA256 of the exact uncompressed JSON. No authoritative state or RNG changes. Serialization is streamed into gzip; diagnostic I/O occurs after simulation measurements. A failed sidecar write leaves inline evidence intact, marks that seed failed and permits other seeds to finish.

The temporal analyzer resolves sidecars only as it processes each world, verifies compressed integrity, identity, byte count and SHA256 before parsing, and refuses absolute, parent traversal or resolved paths escaping the evidence directory. Its output is written sequentially with exclusive creation, so neither all-world temporal data nor a multi-gigabyte summary string is required. Interrupted/failed summaries remain incomplete JSON and must not be treated as validation evidence. Ordinary inline reports remain compatible. The eight-world R3 raw report already exceeds122MB, so per-world storage is required before a100×100000 temporal run. The real seed0/tick1000 sidecar smoke reproduced the inline fixture's complete temporal summary and world hash `b21177ecbc60aacfb3425b32ec123e478ebd5233d09cd19b0c593ff13e9c5aef`.
